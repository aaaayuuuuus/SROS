# 🌱 Sustainable Route Optimization System (SROS)

A smart and eco-friendly route planning system that optimizes travel paths while minimizing environmental impact, cost, and travel time.

---

## 🚀 Overview

**SROS (Sustainable Route Optimization System)** is designed to compute optimal routes using intelligent algorithms that consider multiple real-world factors such as:

- Distance  
- Traffic conditions  
- Fuel consumption  
- Environmental impact  

---

## 🎯 Features

- 📍 Intelligent route optimization  
- 🌍 Eco-friendly path selection (low carbon routes)  
- 📊 Cost & distance minimization  
- 🗺️ Map-based visualization  
- ⚡ Fast and efficient algorithms  
- 🔄 Dynamic routing (based on inputs)

---

## 🧠 Tech Stack

- **Backend:** Python  
- **Algorithms:** Graph-based optimization (Shortest Path / TSP concepts)  
- **APIs:** Map APIs (Google Maps / OpenStreetMap if used)  
- **Frontend:** HTML, CSS, JavaScript  
- **Deployment:** vercel

---

## 🧪 How It Works

The system models the road network as a **graph**, where:

- Nodes → Locations  
- Edges → Routes  
- Weights → Distance / cost / emissions

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/aaaayuuuuus/SROS.git
cd SROS
```

### 2️⃣ Create virtual environment
```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
```

### 3️⃣ Install dependencies
```bash
pip install -r requirements.txt
```

### 4️⃣ Run the project
```bash
python app.py
```
